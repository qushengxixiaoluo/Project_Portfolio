# 智能温控器固件 (smart-thermostat)

基于 ESP32 的桌面温控器，用于恒温控制加热台。

## 核心功能
- PID 恒温算法：Kp=2.4, Ki=0.8, Kd=1.2，目标温度误差 ±0.5°C
- PWM 控制加热片，频率 1kHz
- OLED 显示当前温度与设定曲线
- 串口命令：`SET 80` 设置目标温度，`READ` 读取当前温度

## 硬件
- 主控：ESP32-WROOM-32
- 温度传感器：MAX6675（热电偶）
- 加热元件：5V 10W 加热片

## 联调注意事项
联调时必须先接热电偶再上电，否则 MAX6675 会返回 -1 导致 PID 输出饱和。
